# Shift 02 — Visual asset credits

Shift 02 uses optional external glTF scene-dressing models from Kenney's **Space Kit** and **Factory Kit**, distributed under the **Creative Commons CC0 1.0 Universal** license.

- **Kenney Space Kit**: https://kenney.nl/assets/space-kit
- **Kenney Factory Kit**: https://kenney.nl/assets/factory-kit
- **License**: https://creativecommons.org/publicdomain/zero/1.0/
- **Runtime format**: glTF Binary (.glb)

## Models used

Space Kit models:
- `satelliteDish.glb`
- `satelliteDish_detailed.glb`
- `satelliteDish_large.glb`

Factory Kit models:
- `machine.glb`
- `crane-lift.glb`
- `machine-window.glb`
- `pipe-large-curve.glb`

Sources:
- Space Kit mirror: https://github.com/euuuuuuan/voidclad-public/tree/main/assets/vendor/kenney_space_kit
- Factory Kit source: https://github.com/shorepine/kenney/tree/main/3d/factory

The level can still be entered if optional model requests fail; the relay puzzle and movement code remain available. An internet connection is needed to fetch the imported models unless the browser has cached them. The environment's authored geometry, materials, procedural floor texture, lighting, and effects remain local to the game.
