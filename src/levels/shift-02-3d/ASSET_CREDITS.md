# Shift 02 — Visual asset credits

Shift 02 uses optional external glTF scene-dressing models from Kenney's Space Kit, distributed under the **Creative Commons CC0 1.0 Universal** license.

- **Kenney — Space Kit**: https://kenney.nl/assets/space-kit
- **License**: https://creativecommons.org/publicdomain/zero/1.0/
- **Runtime format**: glTF Binary (.glb)
- **Models used**: satellite dish, detailed satellite dish, large satellite dish
- **Source mirror used by the loader**: https://github.com/euuuuuuan/voidclad-public/tree/main/assets/vendor/kenney_space_kit

The level can still be entered if these optional model requests fail; the scene's own geometry, relay puzzle, and movement code remain available. An internet connection is needed to display the imported models when the browser has not cached them.
